# 数据分析与 SQL 提示词

## 1. SQL 查询生成

```
请根据以下需求生成优化的 SQL 查询：

数据库：{PostgreSQL / MySQL / SQL Server / Snowflake}
表结构：
```sql
{粘贴 CREATE TABLE 语句或描述表结构}
```

查询需求：{用自然语言描述想查什么}

要求：
1. 使用 CTE 而非多层子查询（提高可读性）
2. 考虑索引利用（WHERE 条件顺序与复合索引对齐）
3. NULL 处理（COALESCE / IS NULL 的判断逻辑是否正确）
4. 大数据量下的性能考虑（LIMIT、分页、避免全表扫描）
5. 输出 SQL + 各部分的注释说明
6. 给出预期执行计划中可能耗时的节点
```

## 5. A/B 测试分析

- 对照组 A：{样本量}，{描述}
- 实验组 B：{样本量}，{描述}
- 核心指标：{转化率/留存率/点击率 等}

数据：
| 组别 | 样本量 | 转化数 | 均值 | 标准差 |
|------|--------|--------|------|--------|
| A    | ...    | ...    | ...  | ...    |
| B    | ...    | ...    | ...  | ...    |

请输出：
1. 假设检验方法选择（t 检验 / Z 检验 / χ² 检验）
