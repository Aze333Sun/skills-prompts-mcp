## 编写要点

1. **代码模板必须来自项目真实代码**：从源码中挑最典型、最规范的实现改写，不要凭空写。
2. **禁止事项要有对照**：错误示例 + 正确做法成对出现，AI 才能避免。
3. **验证检查清单控制在 3-6 项**：只列关键项，过细的检查会稀释注意力。
4. **验证命令要可运行**：优先用 `grep -r "特征" src/ | wc -l` 这类计数命令。
5. **未确认的内容标 `[待确认]`**：不要编造规则。
