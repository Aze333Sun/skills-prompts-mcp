# INDEX.md 模板

在知识体系根目录创建 `INDEX.md` 时，复制本模板并替换 `{{占位符}}`。

---

```markdown
# {{项目名称}} 知识总索引

## 快速导航

| 我需要... | 查看 |
|----------|------|
| 了解术语 | [术语表](GLOSSARY.md) |
| 查看约束 | [Skills体系](SKILLS/README.md) |

## 最新Skills

| Skills | 版本 | 状态 | 最后更新 |
|--------|------|------|----------|
| CORE_001 | v1.0 | ✅ 活跃 | {{日期}} |
| ... | ... | ... | ... |

## 使用说明

### 上下文加载策略

1. **最小加载**（~10KB）：INDEX + GLOSSARY
2. **标准加载**（~20KB）：最小加载 + 全部 CORE Skills
3. **完整加载**（~25KB）：标准加载 + 1-2 个领域 DETAILED Skills

### 任务映射

| 任务类型 | 必读Skills | 预估上下文 |
|----------|------------|------------|
| {{任务类型1}} | {{CORE/DETAILED 编号列表}} | ~{{N}}KB |
| {{任务类型2}} | {{编号列表}} | ~{{N}}KB |

### 快速查询

- {{问题领域1}} → [CORE_{{编号}}](SKILLS/CORE/SKILL_CORE_{{编号}}_{{名称}}.md)
- {{问题领域2}} → [CORE_{{编号}}](SKILLS/CORE/SKILL_CORE_{{编号}}_{{名称}}.md)
```

---

## 编写要点

1. **任务映射表是 INDEX 的核心**：每种常见开发任务一行，列出必读 Skills 编号。从项目的实际开发场景出发（新增接口、数据访问、配置变更等）。
2. **链接必须指向真实存在的文件**：写完后逐个核对路径。
3. **预估上下文按文件实际大小估算**：每个 CORE ~2KB，每个 DETAILED ~1-2KB。
4. **GLOSSARY.md 同步创建**：收录项目领域术语（业务名词、技术缩写），每条附定义、英文、关联 Skill 链接。
