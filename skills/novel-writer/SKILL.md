# 长篇网文写作

## 总流程

```
选题诊断 → 核心卖点 → 黄金三章 → 分卷章纲 → 逐章执行 → 章末加压 → 完稿审查
```

每步有对应框架。不需要全流程时，直接跳到当前最需要的那一步。

---

## 第一步：选题诊断

**拿到一个点子，先问四件事：**

| 问题 | 判断标准 |
|------|---------|
| **卖点是什么？** | 读者为什么选你这本而不是排行榜上另外100本？ |
| **冲突引擎是什么？** | 什么矛盾能持续产生事件，跑过前20章？ |
| **异常局面是什么？** | 主角的处境有什么不寻常？有什么让读者觉得"我倒要看看"？ |
| **适合什么长度？** | 短篇（<10万字）/ 中篇（10-50万）/ 长篇（50-200万）/ 连载（200万+）？ |

**四问全部模糊 → 不要开写，先压成一句话 hook。**

> Hook 公式：`[主角]在[异常局面]下必须[做什么]，否则[代价]`

**题材消费点速查：**

| 题材 | 核心消费点 | 开篇抓手 |
|------|-----------|---------|
| 玄幻/仙侠 | 升级快感、世界观奇观 | 开局危机/金手指激活 |
| 都市/现实 | 代入感、逆袭爽感 | 身份反差/重生优势 |
| 言情/纯爱 | 关系张力、情感满足 | 初遇冲突/立场对立 |
| 悬疑/推理 | 谜题驱动、智力快感 | 尸体/失踪/异常现象 |
| 科幻/末世 | 生存压力、系统新奇 | 灾难降临/系统激活 |
| 游戏/电竞 | 竞技燃点、逆袭爽感 | 新手村/菜鸟逆袭 |

---

## 第二步：核心卖点与故事引擎

### 三个必答题

1. **Hook（一句话钩子）**
   公式：`当[异常事件]发生，[主角]必须[核心行动]，否则[不可逆代价]`

2. **Premise（故事前提，3-5句）**
   说清：世界什么样 → 主角是谁 → 异常在哪 → 他要做什么 → 代价是什么

3. **故事引擎（前20章动力源）**
   至少从以下选一种：
   - **生存压力**：不做就死（末世、追杀、绝症）
   - **升级驱动**：不做就弱（修炼、竞技、职场）
   - **谜题牵引**：不查就不知道（悬疑、解谜、探案）
   - **关系拉扯**：不进就退（追妻/追夫、对手变恋人）
   - **复仇/翻身**：不成就被踩（重生、逆袭、打脸）

**引擎不能只有一个。** 主流长篇网文至少有两层引擎——外层（升级/复仇）+ 内层（感情线/身世谜）。

## 第三步：黄金三章（开头）

### 三章的各自任务

| 章节 | 核心任务 | 字数参考 |
|------|---------|---------|
| **第1章** | 给抓手：让读者在500字内知道主角是谁、处境多异常、为什么往下看 | 2500-4000字 |
| **第2章** | 展卖点：核心设定/金手指/核心冲突亮相，让读者知道你卖的是什么 | 2500-4000字 |
| **第3章** | 定方向：第一个小高潮或第一个明确行动目标，让读者知道"接下来要看什么" | 2500-4000字 |

### 第一章开头三秒公式

**500字内必须出现（至少2项）：**
- 主角的**名字**和一个**具体动作**
- 一个**异常现象**或**紧迫处境**
- 一个让读者**好奇的问题**

```
✅ "陈默盯着手机屏幕上的数字——银行余额：3.27元。距离发工资还有11天。"
❌ "在遥远的青云大陆上，修炼体系已传承万年……"
```

### 黄金三章禁忌
- 开头堆设定、世界观、历史背景
- 主角迟迟不出现或不行动
- 第一章结束还没出现异常局面
- 前三章没有一次情绪起伏
- 主角像导游一样介绍世界而不是活在里面

## 第四步：分卷与章纲

### 分卷公式

每卷 = `一个最小目标 → 不断受阻 → 卷末兑现`

| 卷段 | 字数 | 功能 |
|------|------|------|
| 第一卷 | 8-15万字 | 立人设、展卖点、建立核心冲突、给第一个大满足 |
| 第二卷 | 10-20万字 | 扩大格局、引入新势力、升级冲突等级 |
| 第三卷起 | 15-25万字/卷 | 支线展开、人物成长、逐步收束 |

### 章纲写法

章纲不是大纲——是每章的**"四件事清单"**：

```
第N章 章纲
- 主角想做什么：（目标）
- 什么阻止他：（阻碍）
- 局面变成什么：（变化）
- 读者为什么看下一章：（追更点）
```

**前20章必须有章纲。** 没有章纲的长篇网文，中期必散。

### 章纲节奏模板

前20章的节奏可以按这个框架排：

```
第1-3章：黄金三章（抓手→卖点→方向）
第4-6章：展开设定，第一次小收获/小胜利
第7-9章：引入第一个重要配角/盟友/对手
第10-12章：第一次真正的危机/失败
第13-15章：主角应对、成长、反击准备
第16-18章：第一次大高潮/打脸/逆袭
第19-20章：收束第一卷，引出更大悬念 → 进入第二卷
```

## 第五步：逐章写作

### 每场戏的最小结构

```
目标 → 阻碍 → 变化
```

没有**变化**的戏 = 废戏，删、并、压。

### 场景路由（遇到具体问题直接跳转）

| 症状 | 诊断 | 修复方向 |
|------|------|---------|
| 读者说"这段好无聊" | 场景无变化 | 检查目标→阻碍→变化链 |
| 读者说"这人怎么突然这样" | 人物动机断裂 | 补触发事件/内心反应 |
| 读者说"看迷糊了" | 场景转场断裂 | 补过渡句/时空锚点 |
| 读者说"对话好假" | 对白腔调统一 | 每人重写一句口头禅/说话习惯 |
| 读者说"AI写的吧" | AI味（见去AI味模块） | 按六项去AI味逐项修复 |
| 读者说"这章看完不想追了" | 章末无力 | 补悬念钩子/情绪余韵/下一章预告 |

### 对白写作三原则

1. **每个人说话带身份**：职业、年龄、性格、和对方的关系——全部影响措辞
2. **对白是行动不是解释**：角色说话是为了达到目的，不是为了给读者解释设定
3. **对白之间要有"刀口"**：每段对话要么推进局势，要么改变关系，要么暴露信息——三者至少占一

### 转场规则

| 转场类型 | 正确做法 |
|----------|---------|
| 时间跳切 | 第一句给时间锚点："三天后"、"那一架打完的第二天" |
| 空间切换 | 第一句给空间锚点："城西的训练场比城东的大了三倍" |
| 视角切换 | 第一句给新视角角色的名字或标志性物品 |
| 章末→下章 | 章末落在变化上，下一章第一拍接住 |

## 第六步：章末加压

### 章末五问（每章写完必答）

1. 这章最后一句，读者会不会想"然后呢？"
2. 主角的处境比这章开始时更好了还是更坏了？（必须变化）
3. 有没有一个未解的问题/悬念让读者必须看下一章？
4. 情绪有没有波动？（一章之内至少一次情绪起伏）
5. 读者看完这章，会不会想在评论区催更？

### 章末钩子六式

| 钩子类型 | 示例思路 |
|----------|---------|
| **悬念断章** | 在信息即将揭露的瞬间切掉——"门打开，里面站着的是——" |
| **危机降临** | 章末出现新的威胁或困难 |
| **反转** | 章末揭示前面的某个认知是错的 |
| **承诺预告** | "明天，就是宗门大比的日子了" |
| **情绪余韵** | 不是情节钩子，而是一段有感染力的情绪收尾 |
| **关系变化** | 两人关系发生微妙改变——"从那天起，她再也没有叫过他全名" |

## 第七步：去 AI 味

### 六项必杀

| AI味症状 | 修复方法 |
|----------|---------|
| 空泛总结 | 删掉"总的来说""这件事情告诉我们"类句子，让事件自己说话 |
| 气氛套话 | "空气中弥漫着紧张的气息"→ 换成具体的声音/动作/体感 |
| 对白像说明书 | 让人物在冲突中说话，不是在科普中说话 |
| 人物腔调统一 | 每个角色分配1-2个口癖/说话习惯，全文保持一致 |
| 句子太工整 | 故意打破句式——长句后跟短句，整句后跟碎句 |
| 动作太"小说" | "他微微一笑"→ 他嘴角动了一下 / 他"哼"了一声 / 他没说话，转过了身 |

### 去AI味铁律

- **能用动作，不用总结**：不说"他很生气"，写他做了什么
- **能用对白，不用解释**：让人物自己说出来，不用旁白帮腔
- **能写具体，不写抽象**："他等了好久" → "他从中午等到天黑"
- **每个人说话带标签**：去掉对话引导句，读者也能分辨是谁在说话

## 第八步：一致性审查

### 每章写完六查（交付前必过）

| 序号 | 检查项 | 问自己 |
|------|--------|--------|
| 1 | 剧情因果 | 关键事件有前提吗？关键决定有触发吗？关键变化有后果吗？ |
| 2 | 人物目标 | 主角这章到底想做什么？过程中有无无故漂移？ |
| 3 | 情绪关系 | 情绪有没有来路？关系温度跟上章对得上吗？ |
| 4 | 身体信息 | 伤势/疲劳/秘密/已知信息有没有丢？ |
| 5 | 场景转场 | 读者会不会迷路？上场的余力带到了下场吗？ |
| 6 | 章末承接 | 章末收在变化上了吗？下一章第一拍能接住吗？ |

**任意2项不稳 → 先修，不交稿。**

---

## 第九步：常见病速诊

| 症状 | 病因 | 速效药 |
|------|------|--------|
| 开头没人看 | 卖点露头太慢 | 第一章500字内出异常局面 |
| 读到第5章弃了 | 没有追更点 | 每章结尾加压，至少留一个悬念 |
| 中期写不下去 | 故事引擎不够 | 加一条支线/新角色/隐藏冲突 |
| 人物像工具人 | 没有独立动机 | 给每个重要角色写一句"ta想要什么" |
| 评论区说"水" | 场景无变化 | 回查每场戏的目标→阻碍→变化链 |
| 感觉像AI写的 | 六个AI味症状至少中2个 | 按去AI味六项逐条清理 |
