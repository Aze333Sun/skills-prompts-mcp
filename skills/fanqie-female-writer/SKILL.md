# 番茄小说女频写作

> 本 Skill 继承 `fanqie-novel-writer` 全部番茄平台策略（推荐机制、爽点密度、章末钩子、变现模式等），不再重复。本文档只写女频增量策略。

## 女频读者心理

### 番茄女频读者画像

| 群体 | 占比 | 核心需求 | 弃书触发器 |
|------|------|---------|-----------|
| 学生/年轻白领 | 45% | 甜宠治愈、代入女主 | 女主太弱/太作/恋爱脑无脑 |
| 宝妈/家庭女性 | 25% | 爽文解压、种田慢生活 | 节奏太慢、剧情拖沓 |
| 通勤碎片族 | 20% | 快节奏情感刺激 | 虐太久不给糖 |
| 核心书虫 | 10% | 创新设定、深度情感 | 套路化、模板化 |

### 女频读者的核心驱动力

女频读者追更不是因为"主角变强了"，而是因为：

- **情感满足**：他到底爱不爱她？什么时候表白？什么时候在一起？
- **关系变化**：他们的关系从敌人→朋友→恋人→？
- **身份悬念**：她的真实身份什么时候暴露？他什么时候知道真相？
- **甜虐交替**：虐的时候想要甜，甜够了想要点虐来调味
- **代入感**：女主的处境我经历过/我幻想过

> **与男频的本质区别：男频追"他有多强"，女频追"他们怎么样了"。**

## 番茄女频六大热门题材

### 1. 现代言情 / 甜宠

**核心消费点**：CP 感、甜度、暧昧拉扯
**番茄特有**：节奏快于传统言情，甜度必须更高

**结构框架**：
```
第1-3章：男女主初遇 → 必须有冲突/误会/反差（不能平淡相识）
第4-8章：被迫相处 → 同一公司/邻居/契约关系 → 暧昧升级
第9-15章：感情升温 + 情敌/误会/危机 → 第一个情感小高潮
第16-25章：确立关系 or 重大转折 → 甜度拉满
第26章起：外部危机 → 两人携手面对 → 感情深化
```

**番茄甜宠爽点公式**：
- 男主的"冷面只对你暖" → 每 3-5 章展示一次
- 女主被欺负 → 男主护短（最经典的番茄甜宠爽点）
- 暗恋/双向暗恋 → 差点被发现 → 误会 → 更甜

### 2. 古言 / 穿越

**核心消费点**：身份反差、古今碰撞、权谋感情双线
**番茄特有**：穿越开局必须快——第一章就穿，不要铺垫

**分支**：
- **古言权谋**：宫斗/宅斗 + 感情线 → 女主用智慧翻盘
- **古言种田**：穿越到古代发家致富 → 慢节奏但要每章有进展
- **古言甜宠**：王爷/将军 × 穿越女/重生女 → 甜度+爽度

### 3. 重生复仇

**核心消费点**：前世的遗憾和仇恨，今生的碾压和打脸
**番茄特有**：重生后第一件事就必须是"复仇第一步"——不能等

**结构框架**：
```
第1章：前世悲惨结局（500字内）+ 重生到关键时间点
第2-5章：利用前世记忆，完成第一个复仇小目标
第6-10章：遇到前世错过的人 → 感情线展开
第11-20章：复仇持续推进 → 原来前世的真相不止如此
第21章起：更大格局的复仇 + 感情深化 + 前世谜题解答
```

**重生复仇爽点节奏**：
- 每 2-3 章：打脸一个前世欺负过女主的人（从小角色到终极反派，升番逻辑）
- 每 5-8 章：收获前世错过的一个好东西（人/资源/机缘）

### 4. 总裁 / 契约婚姻

**核心消费点**：身份差、权力差带来的禁忌感和突破感
**番茄特有**：开局即冲突——不能铺垫"他怎么成为总裁的"

**经典开局**：
- 契约婚姻/替身新娘/一夜错认
- 女主有求于男主（救家人/还债/复仇）
- 男主对女主有误解（以为她别有用心）

**爽点公式**：
- 男主从冷漠 → 好奇 → 在意 → 离不开
- 女主从被动 → 主动 → 男女主势均力敌
- 身份揭露（女主的真实身份/能力公布）

### 5. 种田 / 基建

**核心消费点**：从零到有的成就感、慢生活治愈感
**番茄特有**：种田文在番茄的节奏比起点快——每天都要有可见的进展

**结构框架**：
```
第1-3章：穿越/重生到穷苦环境 → 第一件事：解决吃饭问题
第4-10章：从做饭/种地/手工开始积累第一桶金
第11-20章：扩大规模 → 带动全村/全族致富
第21章起：接触更大的世界 → 商业/政治线展开
```

**种田爽点**：
- 今天多赚了 XX 文钱 → 明天多开了 XX 亩地 → 后天谁谁谁也来投奔了
- 每章有可见的"资产增加"——哪怕只是多养了两只鸡

### 6. 带球跑 / 萌宝

**核心消费点**：孩子是天然的感情纽带，萌宝是天然的"可爱爽点"
**番茄特有**：萌宝必须尽快出场——第一章结尾或第二章开头

## 女频情感节奏（甜虐交替法则）

### 番茄女频的黄金甜虐比

| 阶段 | 甜虐比 | 节奏 |
|------|--------|------|
| 第1-10章 | 7:3（虐为牵引） | 开局冲突但很快给甜——不能一开始就虐 |
| 第11-20章 | 5:5（情感博弈） | 甜虐交替加速，一波接一波 |
| 第21-30章 | 8:2（确认关系） | 大甜为主，小虐点缀 |
| 第30章+ | 6:4（外部压力） | 虐来自外部而非感情内部 |

**核心原则：虐不超过 3 章不给糖。番茄读者对"虐"的容忍度远低于付费平台——因为没有"我花了钱得看完"的沉没成本。**

### CP 感塑造

**CP 感的三个来源**：

1. **身份反差**：高冷总裁 × 可爱实习生 / 战神王爷 × 穿越沙雕女
2. **立场对立**：对家公司 × 对家公司 / 仇人之子 × 被害者之女
3. **唯一性**：男主只对女主特别——别人面前一座冰山，女主面前一个憨憨

**每 3-5 章必须有一次"CP 高光时刻"**：
- 他为她做了一件"不可能"的事
- 她在他最脆弱的时候出现
- 两人被迫独处一室
- 意外肢体接触 → 两人都慌了

## 女频章节结构

比男频多一个"情感节拍"层：

```
【章首情感钩子】（50字）
上一章结尾的情感余韵或本章即将的情感波动

【正文推进】（1500-2000字）
- 主线剧情推进
- 其间必须穿插至少1个"情感瞬间"（一个眼神/一句话/一个动作）

【情感节拍】（300-500字）
- 本章的核心情感变化：关系近了/远了/误会了/明白了
- 这不是"心理描写大段"，而是一个具体的互动场景

【章末钩子】（100-200字）
- 情感钩子：他到底什么意思？她接下来会怎么做？
- 或情节钩子：即将发生的危机/揭露
```

## 女频去 AI 味专项

除继承通用去 AI 味规则外，女频特有问题：

| AI 味症状 | 女频表现 | 修复 |
|-----------|---------|------|
| 情感描写作文化 | "她心中涌起一股暖流" | 写她的身体反应：她攥紧了衣角 / 她没说话，嘴角却翘了起来 |
| 男主"霸总模板" | "他冷冷地说""他眸色一暗" | 给男主一个独特的习惯动作/口癖，打破模板 |
| 女主苍白无力 | 除了"善良可爱"没有特点 | 给女主一个明确的欲望+一个明确的缺陷 |
| CP 互动套路 | 全是壁咚+公主抱+醉酒 | 创造独特的CP专属互动——只属于这两个人的相处方式 |

## 女频自检（L0 女频专属）

在 `fanqie-novel-writer` 的 L0 基础上追加：

| 检查项 | 标准 |
|--------|------|
| 这一章的情感变化是什么？ | 必须有——关系近了/远了/误会了/明白了 |
| 虐了多久了？ | 超过3章无甜 → 立刻在下一章给糖 |
| CP 高光时刻 | 每3-5章至少有一次 |
| 女主有行动吗？ | 不能全程被动——女主必须有1个主动动作 |
| 男主有反差吗？ | 对外人和对女主的反差表现 |
