# 番茄小说男频写作

> 本 Skill 继承 `fanqie-novel-writer` 全部番茄平台策略，不再重复。本文档只写男频增量策略。

## 男频读者心理

### 番茄男频读者画像

| 群体 | 占比 | 核心需求 | 弃书触发器 |
|------|------|---------|-----------|
| 碎片打工人 | 40% | 解压爽感、打脸逆袭 | 主角怂/憋屈/被欺负不还手 |
| 学生党 | 30% | 升级快感、热血竞技 | 升级太慢、战斗力崩坏 |
| 睡前阅读 | 20% | 沉浸式异世界体验 | 剧情无聊、战斗水字数 |
| 核心老书虫 | 10% | 创新设定、反套路 | 模板化开局、套路太明显 |

### 男频读者的核心驱动力

- **升级快感**：主角从弱到强，每次突破都有明确的"变强了"的体感
- **打脸逆袭**：被看不起 → 证明自己 → 对方震惊/后悔/被打脸
- **实力碾压**：主角的底牌一张接一张，让对方绝望
- **资源获取**：获得好东西——宝物/功法/机缘/小弟/势力
- **格局扩大**：从一城到一国到一界到万界，世界越开越大

> **与女频的本质区别：男频追"他有多强"，女频追"他们怎么样了"。**

## 番茄男频六大热门题材

### 1. 都市重生 / 逆袭

**核心消费点**：利用前世记忆/未来信息降维打击
**番茄特有**：重生后第一章就要开始"用信息差赚钱/变强"——不能等

**经典开局**：
- 重生回高中/大学 → 第一件事：买比特币/买房/投资未来巨头
- 重生回关键转折点 → 挽回前世最大遗憾
- 获得未来 N 年记忆 → 第一步：赚第一桶金

**爽点节奏**：
```
第1-3章：重生 + 第一个小目标达成（第一次小爽）
第4-8章：积累第一桶金/第一批资源 → 第二次小爽
第9-12章：遇到前世敌人 → 第一次打脸（中爽）
第13-18章：事业扩大 + 身边人震惊 → 持续打脸
第19-25章：遇到前世大BOSS → 第一个大高潮（大爽）
```

### 2. 玄幻 / 仙侠升级

**核心消费点**：修炼体系、越级挑战、奇遇机缘
**番茄特有**：升级节奏快于起点——不能水修炼过程

**升级体系设计原则**：
- 境界 5-8 个大境界，每境界 3-5 个小等级
- 每 5-8 章突破一个小等级
- 每 15-20 章突破一个大境界
- 每次突破伴随一个"越级挑战"的机会

**战斗场景公式**：
```
主角当前实力 < 对手实力 → 激活金手指/隐藏底牌 → 越级反杀 → 旁观者震惊 → 收获战利品
```

### 3. 系统流

**核心消费点**：系统任务的完成感和奖励的惊喜感
**番茄特有**：系统必须在第一章激活，任务和奖励要在前 3 章展示

**系统设计公式**：
- 发布任务 → 主角执行 → 超额完成 → 惊喜奖励 → 奖励立即产生效果
- 每 2-3 章一个新任务
- 奖励必须马上在后续剧情中"爽"出来

### 4. 赘婿 / 女婿流

**核心消费点**：隐藏身份逐渐揭露、岳母/亲戚从看不起到跪舔
**番茄特有**：身份揭露按"升番逻辑"——从小身份到大身份逐步揭露

**经典开局**：
- 入赘三年被全家看不起 → 第 1-3 章：第一个小身份揭露（某个领域的专家）
- 第 5-10 章：第二个身份揭露（某个大势力的成员）
- 第 15-20 章：真正的身份揭露（战神/神医/商业帝国的幕后掌控者）

**每次揭露必须包含**：家人的震惊 + 外人的震惊 + 女主的反应

### 5. 游戏 / 电竞

**核心消费点**：竞技燃点、操作秀、从菜鸟到大神
**番茄特有**：游戏设定要简单明了——不能上来就是复杂数值系统

**竞技节奏**：
```
每场对局 = 遇到困难 → 看似要输 → 主角秀操作 → 反杀 → 全场震惊
```

### 6. 末世 / 生存

**核心消费点**：危机压力、资源收集、基地建设
**番茄特有**：末世降临必须在第一章发生——不能铺垫"末世前的生活"

**末世节奏公式**：
```
第1章：末世降临 + 主角觉醒能力/系统
第2-5章：第一批资源收集 + 第一次战斗
第6-10章：遇到幸存者 → 组建小队/基地
第11-20章：基地发展 + 遇到其他势力
```

## 男频爽点系统（番茄强化版）

### 三种核心爽点类型

**1. 升级爽**
- 突破境界（伴随天地异象更佳）
- 获得新能力/新技能
- 装备/武器升级
- 每次升级后立即安排一场战斗检验新实力

**2. 打脸爽**
- 被看不起 → 亮出实力 → 对方震惊/后悔/恐惧
- 打脸对象按升番排列：路人甲 → 小反派 → 大反派 → 终极反派
- 每次打脸必须有"旁观者反应"——群众的震惊是打脸爽的必要组成部分

**3. 收获爽**
- 奇遇/机缘：别人找不到的宝贝被主角找到
- 捡漏：在所有人都看走眼的地方发现价值
- 收小弟/收势力：高手主动来投奔
- 资源暴涨：一次性获得大量财富/资源

### 男频爽点密度

| 章节区间 | 每章最低爽点 | 每章推荐爽点 |
|---------|------------|------------|
| 第1-10章 | 2个 | 3个（含1个升级/金手指激活+1个打脸/收获） |
| 第11-30章 | 1.5个 | 2-3个 |
| 第30章+ | 1个 | 2个 |

**一句话：前10章是最密集的爽点轰炸区，不能有空洞章节。**

## 男频章节结构

```
【章首燃点】（50字）
接住上一章的余温，或直接用行动/冲突开场
男频章首不宜抒情——直接进入动作或对话

【本章目标/任务】（隐于叙事）
主角这章要做什么？（读者心里必须有"这一章的目的地"）

【推进 + 第一个小爽点】（600-800字）
行动 → 遇到阻碍 → 展现实力/金手指 → 第一次推进成功

【升级/转折】（300-500字）
局面意外升级 or 突破一个小等级 or 发现意外机缘

【本章大爽点】（500-800字）
本章的核心满足：打脸/突破/收获/战斗胜利
必须有"观众反应"——周围人的震惊/崇拜/嫉妒

【章末加压钩子】（100-200字）
- 更强的敌人即将出现
- 更大的机缘在召唤
- 隐藏的危机浮出水面
- 身份即将暴露（赘婿流）
```

## 战斗力体系设计

### 男频力量感五维

| 维度 | 说明 | 每N章升级一次 |
|------|------|-------------|
| **修为/等级** | 核心战力 | 5-8章（小等级），15-20章（大境界） |
| **装备/武器** | 战力加成 | 10-15章（换装/升级） |
| **技能/功法** | 战斗手段多样化 | 5-10章（新技能习得） |
| **势力/小弟** | 背景力量 | 20-30章（势力扩张） |
| **底牌/秘密** | 越级战斗的资本 | 始终有1-2张未揭底牌 |

**关键：五维不能同时升级——要有先后、有节奏，读者才能持续有"新鲜感"。**

## 男频去 AI 味专项

| AI 味症状 | 男频表现 | 修复 |
|-----------|---------|------|
| 战斗描写套路化 | "他一拳轰出，天地变色" | 每场战斗有1个独特的细节——那把剑断了半截，他用断剑的缺口卡住了对方的兵器 |
| 升级像报告 | "他的修为突破到了金丹期" | 升级要有代价、有体感、有身体细节——筋脉撕裂的痛/头脑突然清明的爽 |
| 角色全是工具人 | 配角只有"震惊"这一个反应 | 给重要配角一个独立动机——他为什么帮主角/为什么跟主角作对 |
| 金手指像说明书 | 系统播报满屏飞 | 系统提示要精简，关键奖励用人物反应来代替系统说明 |

## 男频自检（L0 男频专属）

| 检查项 | 标准 |
|--------|------|
| 这章爽点是什么？ | 升级/打脸/收获——至少一个，最好两个 |
| 主角变强了吗？ | 不一定是等级提升——新技能/新装备/新信息也算 |
| 有"观众反应"吗？ | 打脸和收获必须有第三方反应 |
| 战力崩了吗？ | 对照五维检查——不能上一章打不过、这章秒杀 |
| 底牌还够吗？ | 至少保持1-2张未揭底牌，不要一口气全亮 |
