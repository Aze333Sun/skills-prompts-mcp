# 番茄小说平台写作

## 平台认知

番茄小说是字节跳动旗下的**免费阅读 + 广告变现**平台。理解这一点，就理解了番茄写作的全部逻辑。

### 商业模式决定写作策略

| 维度 | 番茄小说（免费） | 起点/晋江（付费） |
|------|-----------------|-------------------|
| **读者成本** | 零（时间换内容） | 按章付费 |
| **平台收入** | 广告展示 + 广告点击 | 读者付费分成 |
| **作者收入** | 广告分成（阅读量×广告收益） | 订阅分成 + 打赏 |
| **核心指标** | 追读率、完读率、留存率 | 订阅量、均订、追订 |
| **分发逻辑** | 算法推荐（信息流模式） | 编辑推荐 + 排行榜 |
| **读者忠诚度** | 低（免费→随时弃书） | 较高（付费→沉没成本） |
| **读者画像** | 下沉市场为主，碎片化阅读 | 核心读者，阅读习惯成熟 |

### 番茄的推荐算法逻辑（类抖音信息流）

```
新书发布 → 小量测试（100-500曝光）
  ↓ 追读率/完读率达标
进入验证池（500-2000曝光）
  ↓ 数据持续达标
进入放大池（2000-10000曝光）
  ↓ 留存率稳定
进入爆款池（数万曝光起步）
  ↓ 数据下滑
退回小池 → 继续更新等待下一轮推荐
```

**一句话：番茄的推荐完全由数据驱动。编辑不决定你的命运，读者行为数据决定一切。**

### 番茄三大生命指标

| 指标 | 含义 | 生死线 | 爆款线 |
|------|------|--------|--------|
| **追读率** | 看完本章后继续看下一章的比例 | >40% | >65% |
| **完读率** | 从第一章读到最新章的比例 | >20% | >35% |
| **次日留存** | 今天看了、明天还回来的比例 | >30% | >50% |

三个指标中，**追读率是核心中的核心**。追读率低 → 不给量 → 没曝光 → 书就死了。

## 番茄读者画像

### 四大读者群体

| 群体 | 占比 | 阅读场景 | 阅读习惯 | 爽点阈值 |
|------|------|---------|---------|---------|
| **碎片打工人** | 40% | 通勤、午休、排队、上厕所 | 每段 5-10 分钟，随时被打断 | 低——容易满足 |
| **睡前阅读族** | 25% | 睡前 30-60 分钟 | 一口气读多章 | 中——需要持续吸引 |
| **学生党** | 20% | 课间、晚自习、周末 | 集中阅读，时间较充裕 | 中低——看免费的不挑 |
| **核心书虫** | 15% | 随时随地 | 追更、催更、评论区活跃 | 高——比较挑剔 |

**关键推论：你的大多数读者不是在"沉浸式阅读"，而是被广告打断、被微信消息打断、被老板叫走——你的每章必须是一个"断点续读"友好的独立单元。**

### 番茄读者的行为特征

- **弃书成本为零**：不喜欢一秒划走，没有"我付了费必须看完"的沉没成本
- **前三章决定生死**：大多数读者在 3 章内决定留还是走
- **广告打断频繁**：每隔 N 章插一次广告，读者在广告处最容易弃书 → 广告前的结尾必须够强
- **"免费"心态**：对质量宽容但对"无聊"零容忍——可以不精彩，不能没意思

## 番茄特化写作策略

### 一、开篇策略（继承 novel-writer 黄金三章，番茄强化版）

番茄的开篇比任何平台都重要。你的第一章需要有**双重任务**：

**任务一：抓住读者（通用要求）**
- 500 字内主角亮相 + 异常局面
- 1500 字内核心卖点暴露

**任务二：骗过算法（番茄专属）**
- 前 500 字是算法的"第一印象"——如果读者在 500 字位置大量流失，算法判定此文"留存差"，后续推荐断崖式下降
- **第一章必须至少埋 3 个爽点/钩子**，间隔不超过 600 字

```
番茄第一章爽点分布模板：
0-300字：悬念钩子或异常开局 → 读者"怎么回事？"
300-600字：第一个小满足（信息/能力/反差） → 读者"有意思"
600-1000字：冲突升级或第一个小高潮 → 读者"爽！"
1000-1500字：伏笔/更大的悬念 → 读者"后面会怎样？"
1500-2500字：章末强力钩子 → 读者点下一章
```

### 二、节奏策略（番茄核心差异）

| 维度 | 传统付费网文 | 番茄免费网文 |
|------|------------|------------|
| **单章字数** | 3000-5000 字 | 2000-3500 字 |
| **爽点密度** | 每 2-3 章一个小爽点 | **每章至少 1 个小爽点** |
| **高潮间隔** | 10-15 章一个大高潮 | 5-8 章一个大高潮 |
| **每日更新** | 4000-6000 字（1-2 章） | 4000-8000 字（2-3 章） |
| **章末钩子强度** | 中等（读者有付费惯性） | **极高**（免费读者的唯一驱动力是"想知道后面"） |
| **信息密度** | 允许铺垫 | **零铺垫容忍**——每段都在推进 |

### 三、爽点系统（番茄专属强化）

番茄的"爽"有七种核心形态：

| 爽点类型 | 实例 | 适用题材 |
|----------|------|---------|
| **获得/升级** | 获得金手指、突破境界、捡到宝贝 | 玄幻/系统/游戏 |
| **打脸/逆袭** | 被看不起→反杀、被欺负→碾压 | 都市/重生/职场 |
| **身份揭露** | 隐藏身份曝光、真实实力展现 | 都市/玄幻/历史 |
| **知识碾压** | 用现代知识在古代/异世界降维打击 | 穿越/历史/种田 |
| **情感满足** | 确认关系、误会解开、深情告白 | 言情/纯爱 |
| **悬念解答** | 谜底揭晓、真相大白 | 悬疑/推理/末世 |
| **资源获取** | 暴富、捡漏、天降横财 | 都市/种田/末世 |

**番茄爽点铁律：每章至少 1 个爽点，最好 2 个。连续 2 章无爽点 = 追读率断崖。**

### 四、章节结构（番茄版单章模板）

```
【章首勾子】（50-100字）
用一句话或一个场景，接住上一章的悬念或制造本章的期待

【本章目标】（隐于叙事中）
主角这章想做什么？（读者必须能回答）

【发展 + 第一个小爽点/冲突】（600-800字）
推进主线 + 第一个情绪波动

【转折/升级】（400-600字）
局面变化——比主角预想的更难/更意外/更有趣

【第二个爽点/解决】（500-800字）
本章的主要满足点——不一定是彻底解决，但一定有明确进展

【章末强力钩子】（100-200字）
- 新的悬念
- 即将到来的危机
- 身份/秘密即将暴露
- 意想不到的反转
- 或者：一个让人心痒的"预告"
```

**番茄章末钩子必须比付费平台强一倍**——读者没有"我花钱了必须看完"的动力，唯一让他翻下一页的是"太想知道了"。

### 五、前 30 章节奏模板（番茄专属）

```
第1-3章：超强化黄金三章
  - 第1章：异常开局 + 主角特殊性 + 第一个爽点
  - 第2章：金手指/核心设定激活 + 第二个爽点
  - 第3章：第一次打脸/逆袭/解决问题 + 卷末级钩子

第4-8章：持续加压
  - 每章至少1个爽点
  - 展开世界观（但要一边行动一边展，禁止静态科普）
  - 引入重要配角（对手/盟友/恋爱对象）

第9-15章：第一个大高潮区
  - 第9-11章：冲突持续升级
  - 第12-13章：第一个真正的大爽点（打脸大会/大比获胜/身份揭露）
  - 第14-15章：收束+引出更大格局

第16-25章：第二波升级
  - 新地图/新对手/新目标
  - 爽点密度保持每章1-2个
  - 感情线/支线展开（但不能冲淡主线）

第26-30章：第二个大高潮 + 长期悬念锚定
  - 大爽点
  - 埋下贯穿全书的核心谜题/目标
```

## 番茄变现策略

### 收入公式

```
作者日收入 ≈ 当日阅读人数 × 单用户广告价值 × 阅读章节数
```

三个倍增杠杆：
1. **阅读人数**：靠推荐量（追读率决定）→ 写好开头，追读率是推荐量的唯一开关
2. **单用户广告价值**：读者画像影响广告单价（一线城市>下沉市场，但番茄下沉用户基数大）
3. **阅读章节数**：章节越多，单用户贡献越多 → **持续更新是王道**

### 番茄的福利体系

- **新人签约奖**：达到一定字数和数据门槛有奖金
- **全勤奖**：日更达标连续 N 天有额外奖励
- **完本奖**：正常完本有完结奖励
- **版权开发**：优秀作品可进入版权改编通道（短剧/动漫/影视）

## 番茄自检清单（发布前逐章过）

### L0 番茄专属（写前必过）

| 检查项 | 标准 |
|--------|------|
| 这一章的爽点是什么？ | 至少1个明确的爽点，最好2个 |
| 爽点之间间隔多少字？ | 不超过800字，超过则中间插入小钩子 |
| 章末有钩子吗？ | 必须有——悬念/预告/反转/危机——选一种 |
| 这一章可以被跳过吗？ | 不能——每章必须有不可替代的推进 |
| 广告位前的内容够强吗？ | 如果这章在广告之后开始，读者还会回来吗？ |

完整自检流程继承 `novel-writer` 的四层体系（硬性规则→结构质量→读者视角→品牌感），叠加番茄 L0 专属层。

## 绝对禁区

除继承 novel-writer 和 chinese-webnovel 全部禁区外，番茄平台额外禁止：

1. **慢热**：番茄读者没有耐心等你铺垫——开局就必须有东西
2. **连续两章无爽点**：追读率会断崖，算法会判死刑
3. **章节过长**：番茄单章超过 4000 字 → 碎片读者读不完 → 完读率下降
4. **章末"平淡收尾"**：没有钩子的章末在番茄就是自杀——免费读者的下一页全靠钩子驱动
5. **开头堆设定**：番茄第一章出现大段世界观介绍 → 留存率直接归零
6. **过长断更**：断更超过 3 天 → 推荐量大幅下降 → 追读率雪崩
7. **忽视评论区**：番茄读者评论活跃度高，不互动 = 浪费免费的社区温度
